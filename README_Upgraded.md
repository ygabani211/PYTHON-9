# Sales Data Analysis & Visualization Program

A beginner-friendly, menu-driven Python application for loading a CSV sales dataset, exploring its contents, cleaning missing values, calculating descriptive statistics, creating charts, and saving visualizations.

---

## 1. Project at a glance

This project uses **Pandas** to work with tabular data and **Matplotlib** to display and save charts.

You can use it to:

- Load a sales dataset from a CSV file.
- Preview the first or last five rows.
- View column names, data types, and dataset information.
- Sort sales data in descending order.
- Find rows containing missing values.
- Fill or remove missing values.
- Generate descriptive statistics.
- Create six types of visualizations.
- Save the latest generated chart as an image.

> **Important:** The program expects a CSV file. Some operations and chart choices expect columns with particular names or data types. See the notes below.

## 4. How to run the program

1. Open a terminal in the project folder.
2. Install the requirements (see above).
3. Run:

   ```bash
   python sales_data_analyzer.py
   ```

4. Choose an option from the main menu.
5. When asked for a CSV path, enter the path to your dataset. For example:

   ```text
   sales.csv
   ```

   If the CSV is in another folder, enter its full path.

6. Load the dataset before choosing the other operations.

## 5. Main menu explained

| Option | Feature | What it does |
|---|---|---|
| 1 | Load Dataset | Reads a CSV file into a Pandas DataFrame. |
| 2 | Explore Data | Displays a preview, column names, data types, or basic information. |
| 3 | Perform DataFrame Operations | Sorts the `Sales` column from highest to lowest and displays the first five rows. |
| 4 | Handle Missing Data | Finds missing rows, fills numeric missing values with column means, drops incomplete rows, or replaces missing values with a chosen value. |
| 5 | Generate Descriptive Statistics | Displays summary statistics for the dataset, including non-numeric columns. |
| 6 | Data Visualization | Creates a chart selected from the visualization menu. |
| 7 | Save Visualization | Saves the most recently generated chart. |
| 8 | Exit | Closes the program. |

### Option 2: Explore Data

After choosing **Explore Data**, select:

1. First five rows — `df.head()`
2. Last five rows — `df.tail()`
3. Column names — `df.columns.tolist()`
4. Data types — `df.dtypes`
5. Basic information — `df.info()`

### Option 3: Perform DataFrame Operations

The current implementation sorts by a column named exactly `Sales`:

```python
self.df.sort_values(by='Sales', ascending=False).head()
```

If your dataset uses another column name, change `Sales` in the code to the correct column name.

### Option 4: Handle Missing Data

| Choice | Action |
|---|---|
| 1 | Displays rows that contain at least one missing value. |
| 2 | Fills missing values in numeric columns with each column's mean. |
| 3 | Removes rows containing missing values. |
| 4 | Replaces missing values with the value entered by the user. |

**Tip:** Make a copy of your original CSV before cleaning data. The fill and drop choices modify the DataFrame currently held in memory.

### Option 5: Generate Descriptive Statistics

The program runs:

```python
self.df.describe(include='all')
```

This gives a statistical summary of the columns. The exact statistics shown depend on each column's data type.

## 6. Visualizations explained

Choose **Data Visualization** from the main menu.

| Choice | Chart | What it is useful for | Input required |
|---|---|---|---|
| 1 | Bar chart | Comparing values across categories | X and Y columns |
| 2 | Line chart | Showing changes or trends | X and Y columns |
| 3 | Scatter plot | Exploring the relationship between two numeric columns | X and Y columns |
| 4 | Pie chart | Showing how categories contribute to a whole | One numeric Y column |
| 5 | Histogram | Showing the distribution of numeric values | One numeric column |
| 6 | Stacked area chart | Comparing cumulative values across an index | Numeric columns in the DataFrame |

For bar, line, and scatter charts, enter column names exactly as they appear in the CSV header. For example, if the header is `Product`, enter `Product`, not `product`.

### Which chart should I choose?

- Compare product or region totals → **Bar chart**
- Show sales over time → **Line chart**
- Compare two numeric measures → **Scatter plot**
- Show parts of a whole → **Pie chart**
- Understand the spread of sales values → **Histogram**
- Compare cumulative trends → **Stacked area chart**

## 7. Saving a chart

1. Generate a chart using menu option **6**.
2. Return to the main menu.
3. Choose **7. Save Visualization**.
4. Enter a filename, for example:

   ```text
   monthly_sales.png
   ```

The program saves the most recently generated figure using Matplotlib's `savefig()` method. Use an image extension such as `.png`, `.jpg`, or `.pdf`.

If no chart has been generated in the current run, the program displays a message and does not save anything.

## 8. Understanding the code

The program is organized into two classes and one main function.

### `Visualizer`

Responsible for chart creation and saving.

| Method | Responsibility |
|---|---|
| `__init__()` | Sets `current_figure` to `None`. |
| `create_plot(df, plot_type, x_col, y_col)` | Creates the selected chart and stores its Matplotlib figure. |
| `save_plot(filename)` | Saves the most recently stored figure. |

### `SalesDataAnalyzer`

Responsible for loading and analyzing the dataset. It creates one `Visualizer` object and stores the loaded DataFrame in `self.df`.

| Method | Responsibility |
|---|---|
| `__init__()` | Initializes the DataFrame and Visualizer. |
| `load_dataset()` | Asks for a CSV path and loads it with `pd.read_csv()`. |
| `explore_data()` | Shows the selected preview or dataset details. |
| `perform_dataframe_operations()` | Sorts the `Sales` column in descending order. |
| `handle_missing_data()` | Displays, fills, drops, or replaces missing values. |
| `generate_statistics()` | Prints descriptive statistics. |
| `data_visualization()` | Collects the chart choice and required column names. |
| `save_visualization()` | Asks for a filename and calls the Visualizer's save method. |

### `main()`

Creates the `SalesDataAnalyzer` object and runs the main menu inside a loop. The loop continues until the user chooses option **8**.

### Program flow

## 10. Troubleshooting

| Problem | Likely reason | What to do |
|---|---|---|
| `File not found` | The CSV path is incorrect. | Check the filename and folder; try an absolute path. |
| `Sales column not found` | Your CSV does not have a column named `Sales`. | Rename the CSV header or update the column name in the sorting method. |
| Column name error while plotting | The entered name does not exactly match a CSV header. | Copy the name from Explore Data → Display column names. |
| Chart does not appear | The selected columns or their data types may not suit the chart. | Check the columns and use numeric values where required. |
| Nothing to save | A chart has not been generated successfully in this run. | Generate a chart before choosing Save Visualization. |
| `ModuleNotFoundError` | A required library is not installed in the active Python environment. | Run `python -m pip install pandas matplotlib` in that environment. |

## 11. Notes and possible improvements

The screenshots show a simple educational implementation. The following improvements would make it more reliable:

1. **Close old figures:** Call `plt.close()` or close the previous figure before creating another one, to avoid keeping unused figures open.
2. **Validate chart columns:** Check that entered column names exist before plotting.
3. **Validate chart data:** Pie charts need suitable non-negative values; histograms need numeric data; scatter plots need numeric X and Y columns.
4. **Improve missing-value replacement:** `fillna(val)` may not work as intended for every column when the replacement is text. Consider asking for a replacement value appropriate to the selected column.
5. **Avoid accidental data loss:** Keep the original DataFrame or make a backup before dropping rows.
6. **Handle invalid menu input:** Add clear validation and retry prompts for unexpected input.
7. **Improve error messages:** Report the specific problem instead of catching every error with one generic message.

**Implementation detail to check:** In `Visualizer.create_plot()`, the area-chart branch plots all suitable DataFrame columns because it does not pass `x_col` or `y_col`. This matches the current menu, which does not ask the user to select columns for that chart.

## 12. Quick glossary

- **CSV:** A plain-text file format for tabular data, with values separated by commas.
- **DataFrame:** Pandas' table-like data structure.
- **Column:** A named field in a dataset, such as `Sales` or `Product`.
- **Missing value:** A value that is blank or unavailable, commonly represented by `NaN` in Pandas.
- **Mean:** The arithmetic average.
- **Visualization:** A graphical representation of data, such as a bar chart.
- **Figure:** The Matplotlib object that contains a chart and can be saved to a file.
